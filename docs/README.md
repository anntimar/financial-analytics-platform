# Documentação do FinAnalytics

Este diretório reúne os guias técnicos e operacionais do projeto.

## Navegação

- Consulte o `README.md` da raiz para visão geral e execução rápida.
- Use `CONTRIBUTING.md` para preparar contribuições.
- Consulte `SECURITY.md` antes de relatar vulnerabilidades.
- Os demais documentos deste diretório detalham desenvolvimento, arquitetura, testes, dados, deploy e operação.

A documentação acompanha a branch `master`; mudanças de comportamento devem atualizar o guia correspondente no mesmo pull request.
